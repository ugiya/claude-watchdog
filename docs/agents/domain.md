# Domain documentation

This is a single-context repository.

## Read before exploring

- Read root CONTEXT.md when present.
- Read relevant decisions under docs/adr/ when present.
- Read docs/architecture.md for the existing runtime boundaries and invariants.
- Follow AGENTS.md and SECURITY.md.

If CONTEXT.md or docs/adr/ does not exist, proceed without requiring it.
Create domain documentation only when actual terminology or decisions
need recording; do not scaffold empty documents.

## Conventions

Use glossary terms consistently when a glossary exists.
Surface conflicts with recorded decisions instead of silently overriding them.
Domain documentation does not override the project's safety, release,
or privacy requirements.
